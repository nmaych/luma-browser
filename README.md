# Luma Browser

**Luma Browser 是可直接安装运行的 Windows 独立浏览器软件**，基于 Electron、React 和 TypeScript 构建。它拥有自己的应用窗口与浏览器内核，不使用 iframe 模拟，也不依赖系统浏览器外壳。

项目同时保留一个浏览器预览模式，便于开发者在不启动桌面进程时调试界面；发布和正式使用应以 Electron 桌面应用为准。

## 安装与使用

Windows 安装包构建完成后位于：

```text
release/1.19.0/Luma-Browser-Setup-1.19.0-x64.exe
```

双击安装程序即可完成安装。安装程序支持选择安装目录，并会创建桌面与开始菜单快捷方式，无需管理员权限。主程序文件名为 `LumaBrowser.exe`（无空格，与 `chrome.exe`、`SogouExplorer.exe` 的习惯一致），快捷方式仍显示 “Luma Browser”。

当前已发布 **v1.19.0**（2026-11-20）。已发布的版本可在 [GitHub Releases](https://github.com/nmaych/luma-browser/releases/latest) 直接下载：Release 附件包含 `Luma-Browser-Setup-<version>-x64.exe`、`latest.yml`、`.blockmap` 与 `checksums.txt`。`latest.yml` 是应用内自动更新的版本索引，`checksums.txt` 列出每个产物的 SHA256。

## 目录布局

程序文件与用户数据分开存放，与 Chrome、搜狗浏览器一致：升级只替换程序目录，个人数据不受影响。

```text
<安装目录>\                          程序文件
├─ LumaBrowser.exe
├─ resources\app.asar
└─ locales\

%LOCALAPPDATA%\Luma Browser\
├─ User Data\                        用户数据（配置、Cookie、书签、密码）
└─ Update\                           更新
   ├─ update.json                     检查时间、更新偏好、待安装包
   ├─ update.log                      更新日志（超出 512 KB 轮转）
   └─ packages\
      ├─ Luma-Browser-Setup-1.19.0-x64.exe
      └─ previous\                   上一版安装包，用于回滚
```

1.13 及更早版本把用户数据放在 `%APPDATA%\Luma Browser`。1.14 首次启动时会把它移动到新位置：同盘直接改名（瞬间完成），跨盘或文件被占用时复制状态文件并跳过可重建的缓存目录，原目录保持不动。显式传入 `--user-data-dir`（测试与便携运行）时完全遵循环调用方。细节见 [docs/browser-layout-and-updates.md](docs/browser-layout-and-updates.md)，进程与模块划分见 [docs/architecture.md](docs/architecture.md)。

开发环境也可以直接启动未打包的应用：

```bash
cd luma-browser
npm install
npm run build
npm start
```

## 版本策略

版本号遵循 `MAJOR.MINOR.PATCH`，发布时同步更新 `package.json`、设置页版本兜底值与安装包目录：

- **MAJOR（主版本）**：存储结构、IPC 或数据格式出现不兼容变更，需要迁移；升级前会说明影响。
- **MINOR（次版本）**：新增功能、可见交互或界面改版，例如新增截图方式、标签合并。
- **PATCH（修订版本）**：只包含缺陷修复、安全加固、文案与样式微调，不新增功能。

同一版本不重复发布；修复发布中若夹带新功能，应提升 MINOR 而不是继续叠加 PATCH。完整记录见 [CHANGELOG.md](CHANGELOG.md)。

## 页面渲染

每个标签由主进程持有的 `WebContentsView` 承载（`electron/pageViews.cjs`），而不是窗口内的 `<webview>`：

- 标签可以在窗口之间直接搬运（`removeChildView` → `addChildView`），页面进程、滚动位置、表单与播放状态都保留，所以拆分与合并都不会刷新。
- 渲染层只上报页面区域的矩形，由主进程摆放原生视图；缩放、字体、静音、查找、编辑命令通过 `page-view:*` IPC 下发。
- 原生视图会盖住 HTML 浮层：标签悬浮预览改为**独立的透明窗口**，页面完全不动；菜单、地址栏推荐与右键菜单打开时，浮层 DOM 会被镜像到一个覆盖在页面上方的**透明视图**（`electron/overlaySurface.cjs`），点击通过元素路径回放到真实界面，页面既不移动也不截图；面板与对话框仍用一帧无损截图占位，再把页面视图移出窗口（先截图后移出，避免闪白）；查找栏与内置开发者工具则让出空间（顶部 52px / 右侧面板宽度）。

## 功能

- **真实网页浏览**：每个标签由主进程的原生页面视图（`WebContentsView`）承载，各自拥有独立渲染进程，可访问真实网站。
- **完整导航**：标签独立维护浏览器历史，支持后退、前进、刷新、停止加载、主页和网址导航；页面加载期间刷新按钮自动切换为停止按钮。
- **多标签页**：新建、切换、关闭、复制、关闭其他、关闭右侧、恢复关闭的标签；支持按精确落点拖拽排序，切换标签时网页保持运行；标签栏支持方向键 / Home / End 键盘导航。
- **固定标签**：右键把常用标签固定到左侧，固定后只显示图标、不显示关闭按钮，重启后仍在。
- **启动行为可选**：设置里可以选“继续上次的标签页”或“每次打开新标签页”。
- **会话恢复（懒加载）**：重启后标签与标题都回来，但只有当前标签立即加载，其余在首次点开时才创建页面进程，避免启动时一次性拉起全部页面。
- **标签休眠与内存节省**：后台标签闲置到设定时间后自动释放渲染进程内存，播放声音或正在加载的标签不会被休眠；支持设置最大常驻标签数，超出后自动淘汰最久未使用的后台页面；点击标签即可重新加载，也可在标签右键菜单或快捷键中手动休眠。
- **标签拖出与合并**：按下标签开始拖动时就创建好新窗口，指针一离开标签栏，这个窗口就带着**正在运行的页面**跟手移动（上面有标签栏和地址栏，不是截图）；松手处直接变成正式窗口，页面不重新加载、位置不跳动，原窗口留在原地并自动切到另一个标签。拖到别的 Luma 窗口标签栏则合并，页面同样保持运行。
- **阅读模式**：优先提取正文容器并过滤广告、侧栏、面包屑和书籍元信息；提供宋体、黑体、楷体、字号与行距滑动条、浅色/护眼/深色主题，并支持上一章、下一章导航。
- **网页翻译**：内置整页翻译，支持简繁中文、英、日、韩、法、德、西、俄等目标语言；翻译只修改文本节点，不破坏原网页排版、按钮或链接，可随时恢复原文。首次使用会明确提示页面文字将发送给第三方翻译服务，可在设置中随时关闭授权。
- **页内查找**：Ctrl+F 打开查找栏，实时显示匹配数量，Enter / Shift+Enter 在匹配之间跳转，Esc 关闭。
- **视频小窗**：菜单里的「视频小窗」把当前页面正在播放的视频切到系统画中画窗口，再点一次退出。
- **网页截图**：工具栏相机按钮支持保存可见区域、拖动框选任意区域、截取整个页面（长截图）或复制到剪贴板；框选时可调整选区并直接保存或复制，Esc 取消，网页右键菜单与 Ctrl+Shift+X 同样可用。
- **打印与另存为 PDF**：Ctrl+P 打开系统打印对话框，也可从菜单或网页右键菜单将当前页面另存为 PDF。
- **崩溃恢复**：网页渲染进程崩溃或无响应时会显示恢复页，点击“重新加载”即可恢复该标签页；界面进程异常时自动重载并提供重复崩溃保护。
- **广告与跟踪拦截**：基于 EasyList、EasyPrivacy、EasyList China 与 AdGuard 中文规则，每周自动更新并缓存到本机；支持元素隐藏（清理广告留白），地址栏盾牌显示本页拦截数量，并可按网站单独暂停或恢复。离线或规则未就绪时使用内置域名列表兜底。
- **自定义快捷键与老板键**：设置中心可录制任意按键组合，老板键（默认 Ctrl+Shift+L）在任意应用中一键隐藏/恢复所有 Luma 窗口。
- **密码保存与自动填充**：登录表单的捕获与填充都在 WebView 的隔离世界 preload 中完成，页面脚本无法 hook 或伪造；密码通过 Electron safeStorage（Windows DPAPI）加密后仅存于本机，写入采用 tmp+fsync+rename 原子替换并保留 `.bak`，密码库损坏时进入只读保护而不是静默清空。
- **下载位置**：默认保存到程序目录的上一级（安装目录的上层），可在设置 → 通用中更改；下载暂停与续传同样可用。
- **下载暂停与续传**：下载任务可暂停、继续或取消；未完成的任务在重启后保留记录，可从已下载的字节位置继续传输。
- **新窗口转标签**：网页请求打开新窗口时，在 Luma 中创建新标签。
- **智能地址栏**：自动识别域名、localhost、HTTP(S) 地址、Windows/POSIX 本地路径（`file://`）与搜索关键词。
- **最近打开**：工具栏提供最近访问网页的快捷弹层，可直接回到近期页面或打开完整历史。
- **窗口记忆**：自动保存窗口大小和位置，下次启动回到上次的位置；最大化与还原按钮行为与原生窗口一致。
- **内置与自定义搜索引擎**：内置百度（默认）、谷歌、Bing，也可添加带 `%s` 占位符的自定义搜索地址；可在首页、设置或浏览器菜单中切换。
- **书签文件夹**：支持创建、重命名和删除文件夹，添加书签时归档，在书签管理器中筛选或移动。
- **独立历史标签页**：历史记录始终在单独标签页打开，重复进入会复用已有历史标签。
- **书签与历史**：星标收藏、书签栏、文件夹筛选、搜索、历史按日期分组、删除与清空；历史保留上限提升到 5000 条，标签与历史写入采用延迟合并，避免频繁同步阻塞界面。
- **书签图标本地缓存**：站点图标只下载一次，转换为 data URL 存入本地图标缓存（按来源去重、上限 240 个），书签、书签栏与历史直接读取缓存，离线或再次打开时不再重新请求。
- **原生窗口体验**：无边框自绘标题栏、最小化、最大化/还原、关闭、空白标签栏窗口拖动和快捷键。
- **完整右键菜单**：标签页、真实网页内容、地址栏、首页搜索栏、书签、文件夹和历史记录均提供上下文菜单；网页菜单使用系统光标与窗口内容区坐标定位，避免缩放或高 DPI 下偏移。
- **设置中心**：左侧分组导航与分类搜索，包含通用、标签页与地址栏、搜索引擎、快捷键、广告拦截、密码填充、权限管理、隐私安全和数据与关于；网站数据可按网站查看 Cookie、存储与缓存并单独清除。
- **安全隔离**：所有网页运行在沙盒 WebView 中，禁用 Node.js，阻止非 HTTP(S) 导航，默认拒绝摄像头、麦克风、定位和通知权限；界面启用严格 CSP，应用使用单实例锁避免多进程并发写同一份用户数据。
- **明确反馈**：加载进度、页面标题/网址同步、Toast、空状态、断网与 DNS/服务器错误页。
- **扩展**：设置 → 扩展可安装 `.crx` 安装包或加载含 `manifest.json` 的目录，Luma 将其复制到 `Luma Browser\Extensions` 并在每次启动时重新加载；支持启用/禁用、重新加载与移除。带 `action` 的扩展会在地址栏右侧显示图标，点击打开原生 `chrome-extension://` 弹窗，弹窗里的链接会在新标签打开。内容脚本、后台 Service Worker、`chrome.runtime` 消息与 `chrome.storage` 实测可用；不支持角标数字与 `declarativeNetRequest`，拦截请用内置引擎。
- **版本信息与自动更新**：设置 → 数据与关于展示应用版本、运行时版本与三处存储位置；安装版启动 8 秒后检查一次，此后每 4 小时轮询 GitHub Releases。发现新版本默认在后台下载（可关闭），下载完成后可点“重启并安装”立即升级，默认则在**关闭最后一个窗口时静默安装**，下次启动即为新版本；`Update\update.log` 记录全过程，`packages\previous\` 保留上一版安装包用于回滚。
- **统一右键菜单**：网页和内置页面（新标签页、书签、历史、设置）使用同一套右键菜单，包含前进后退、重新加载、打印、另存为 PDF、网页截图、复制/粘贴/全选、添加书签、复制地址与在系统浏览器中打开；内置页面按能力自动隐藏打印与截图项。
- **个性化**：浅色、深色、跟随系统、默认搜索引擎、书签栏开关、减少动态效果。
- **响应式窗口**：宽屏使用完整标签栏；窄窗口切换为移动式底部导航与标签总览。

## 安全加固

- **密码隔离世界**：登录捕获与自动填充由 WebView 的 sandbox preload 在隔离世界完成，页面脚本无法 hook `console`、伪造提交事件或读取凭证 IPC。
- **密码库原子写入**：`tmp + fsync + rename` 替换，保留 `passwords.json.bak`；文件损坏时进入只读保护并显式告警，绝不会用空库覆盖原文件。
- **CSP**：构建产物注入 `default-src 'self'` 的严格 CSP，开发服务器额外通过 `onHeadersReceived` 下发策略；只允许本地脚本、样式与必要的图片/媒体来源。
- **单实例锁**：同一用户数据目录只允许一个进程，避免设置、密码库和下载记录被并发写入。
- **进程崩溃兜底**：网页渲染进程崩溃/无响应时展示恢复页；界面进程异常自动重载，短时间重复崩溃会停止循环并提示重启。
- **广告规则更新**：规则引擎与列表缓存写入采用临时文件替换；更新失败保留上一份可用规则，离线时回退内置列表。

## 已知限制

- 安装包当前未配置代码签名证书，Windows 可能显示 SmartScreen“未知发布者”；自动更新已接入 GitHub Releases，但静默安装仍可能被 SmartScreen 拦截一次。
- 广告规则来自第三方订阅列表，规则解析与元素隐藏覆盖以 EasyList / AdGuard 语法为准。
- 界面文案目前为中文硬编码，尚未接入 i18n。

## 使用方式

1. 在地址栏输入网址、搜索内容或本地文件路径（如 `C:\Users\你\文件.pdf`），按 Enter。
2. 点击 `+` 新建标签页；点击标签切换页面。
3. 使用工具栏星标收藏当前网页。
4. 通过工具栏或菜单打开书签、历史和设置。
5. 拖拽浏览器顶部空白区域移动窗口，使用右上角按钮控制窗口。
6. 关闭应用后再次打开，标签、书签、历史和设置会恢复。

## 开发环境

### 环境要求

- Node.js 22.12 或更高版本
- npm 10 或更高版本
- Windows 10/11（构建 Windows 安装包）

### 启动桌面应用

```bash
cd luma-browser
npm install
npm run dev
```

该命令会同时启动 Vite 开发服务器和 Electron 桌面窗口，支持渲染层热更新。

### 仅调试浏览器界面

```bash
npm run dev:web
```

然后打开 <http://127.0.0.1:5173>。该模式仅用于界面调试，外部网页使用受限的 iframe 预览，不是最终桌面产品形态。

## 构建

```bash
# TypeScript 检查 + 生产渲染文件
npm run build

# 生成 Windows NSIS 安装包（含 Electron 应用）
npm run dist

# 只生成免安装目录，便于快速验证
npm run dist:dir
```

输出目录：

- `dist/`：React 渲染层静态文件
- `release/1.19.0/win-unpacked/`：可直接运行的免安装应用目录（入口 `LumaBrowser.exe`）
- `release/1.19.0/Luma-Browser-Setup-1.19.0-x64.exe`：当前版本的 Windows 安装程序（118.8 MB，SHA256 `9D313F16E9794151C3E30CF37AB154DE5794F432F417C59CEDB62413BA6451DE`）
- `release/1.19.0/latest.yml`、`.blockmap`：自动更新索引与增量更新差异图
- `release/1.19.0/checksums.txt`：各产物的 SHA256 清单（由 `npm run dist` 自动生成）
- `build/`：应用 PNG/ICO 图标

每次构建成功后，脚本会自动删除旧版本遗留的 `win-unpacked` 免安装目录（保留各版本的安装程序），当前版本的免安装目录会保留用于冒烟验证。清理先用递归删除，失败时逐文件删除；仍被占用时会跳过并在下次构建重试，也可以手动执行 `npm run clean:release`。

如果本机从零下载 electron-builder 资源较慢，可以在执行构建时使用镜像：

```bash
ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/ npm run dist
```

## 架构说明

- **主进程**负责 BrowserWindow、窗口控制、权限策略和 WebView 安全拦截。
- **预加载脚本**通过 `contextBridge` 暴露最小桌面 API，不向页面开放 Node.js。
- **渲染层**负责浏览器工具栏、标签、书签、历史与内置页面。
- **WebView 层**负责真实网站渲染。每个访问过外部网页的标签保留自己的 WebView，切换标签不会销毁页面。
- **状态层**统一管理标签、导航历史、书签、历史和偏好；网页标题、网址、加载状态与网络错误实时回写标签状态。
- **本地存储**：桌面模式下标签和浏览数据使用 localStorage；网站 Cookie 与登录态保存在独立持久化分区 `persist:luma-browser`。

## 安全边界

- WebView 禁用 Node.js、启用上下文隔离和 Chromium 沙盒。
- 网页内容仅允许 HTTP(S) 与用户主动打开的本地文件；远程网页不能导航到 `file://`，`javascript:` 等协议会被拒绝。
- 网站权限请求默认拒绝，不会静默授予摄像头、麦克风、定位或通知权限。
- 新窗口请求会被转换为受控标签页。
- 登录网站仍可能要求验证码、二次验证或第三方 Cookie；这是网站自身的访问策略。

## 已知边界

- Luma 不是 Chrome 发行版，不支持安装 Chrome 扩展、Chrome 同步和专有 DRM 流媒体。
- 部分网站会根据客户端环境限制功能；Luma 已在可用范围内去除 Electron 产品标识。
- 安装包当前以 Windows x64 为目标；macOS/Linux 可复用相同架构增加对应 builder 目标。
